# PKG 구축통합관리

더존비즈온 **PKG사업본부** A10(Amaranth10) 구축업무 통합 관리지표 플랫폼.

GCMS 구축진척 원본(2,360건)을 원천으로 **KPI Definition Book(7 Pillar 35개 KPI)** 을 자동 산출하고,
NSM 화면정의서 기준의 PROJECT 등록 · 공수현황 · 정합성 검증 화면을 제공합니다.

핵심은 **계약공수 기준 공수 산정 정책**(작업지침 v2 §1-3)의 구현입니다.
이 정책은 "NSM 시스템 개발 시 그대로 구현될 정책"으로 명시되어 있으며,
본 시스템은 260724 확정 실측값을 **항등식 포함 100% 재현**합니다.

## 실행 방법

### 방법 1 — 웹서버 없이 실행 (권장)

```
pkg-icm/index_standalone.html  →  더블클릭
```

데이터가 HTML에 내장된 단독 실행 파일입니다. 설치·인터넷 없이 동작합니다.

### 원본 엑셀 갱신 (주간 작업)

```bash
cd pkg-icm
python etl_gcms.py <GCMS.xlsx> --assignee <담당자별.xlsx>
python build_standalone.py
```

`etl_gcms.py` 는 파일명의 `YYMMDD` 를 기준일로 자동 인식하고, 실행 시 항등식 검증 결과를 출력합니다.

### 방법 2 — 웹서버로 실행 (개발용)

```bash
cd pkg-icm
python -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

## KPI 산출 상태

각 KPI는 현재 원천 데이터로 산출 가능한 수준을 3단계로 표시합니다.

| 배지 | 의미 | 건수 |
|---|---|---|
| `자동산출` | GCMS 현행 데이터로 공식 그대로 산출 | 19개 |
| `대체산출` | 원천 필드 일부 부재. 지침 명시 대체값으로 근사 산출 | 4개 |
| `연동 필요` | ERP·VOC·ITSM·HR·A10로그 미연동 | 12개 |

> 대체산출 KPI는 카드 하단에 **어떤 필드가 없어 무엇으로 대체했는지**를 명시합니다.

### 납기 지표 3종 체계

납기 판정 기준일에 따라 3개 지표를 분리 운영합니다.

| KPI | 판정 기준일 | 실적 | 용도 |
|---|---|---|---|
| **1.7 납기준수율** | 변경완료예정일(AE) → 구축완료예정일(AD) | 1,522 / 1,606 = **94.8%** | 주간보고 4대 KPI (대표값) |
| **1.9 기본 구축기간 납기준수율** | 구축완료예정일(AD) 단독 | 1,452 / 1,606 = **90.4%** | 납기 변경 미반영 · 1.8 예외 건 판정 |
| **1.8 계약기간준수율** | 계약종료일(AZ) · 설치형 전용 | 137 / 177 = **77.4%** | 설치형 계약 이행 |

```
납기 연장 효과 = 1.7 − 1.9 = 4.4%p  (변경으로 준수 전환 70건)
```

계약기간준수율(1.8)의 **예외 건 22건**(변경완료예정일 보유 = 납기 변경 발생)은
계약기간이 아닌 **기본 구축기간 납기준수율(1.9)** 로 별도 판정합니다.

> **잔여 차이 1건** — 1.8의 모집단(302→301→완료 177)은 확정값과 일치하나
> 준수 건수는 137 vs 확정 143으로 6건 차이가 남습니다. GCMS 보유 컬럼 조합
> (계약종료일 binary / 30일 grace / 예외 폴백 / 모수 축소)으로는 재현되지 않아,
> 스킬 `a10-deadline-compliance` ❸의 원 산출 스크립트 확인이 필요합니다.
> 화면에는 산출값·확정값·차이를 함께 표기합니다.

### 계약공수 기준 공수 산정 (작업지침 v2 §1-3 확정 정책)

```
공수 3종
  표준공수(AH) = 계약공수 base      예상공수(AI) = 유상공수
  투입공수(AJ) = 유상 실투입        무상공수 = 계약공수 − 예상공수  (FoEX 1:N계열만)

계약공수 분기 (Y열 구축구분)
  FoEX교육(1:N)       계약공수=AH   미투입 = 계약공수 × 잔여율          효율계수 ×30%
  FoEX교육(1:N)+방문   계약공수=AH   미투입 = 유상(AI−AJ) + 무상×잔여율   무상분만 ×30%
  방문구축             계약공수=AI   미투입 = AI − AJ                   —
  FoEX교육(단독)       계약공수=AI   미투입 = AI − AJ                   —

특수규칙
  ① 구축 완료 → 미투입공수 0
  ② 완료예정일 경과 미완료 → 잔여율 5% (상한 없이, 진행율 100% 캡 금지)
  ③ 프로젝트구분=추가 & 모듈구분=기타 & 표준공수=0 & 예상공수=0 → 공수 0

구축진행율(가상) = 경과기간 ÷ 구축기간(구축시작일 AB ~ 변경완료예정일 AE→구축완료예정일 AD)
  ※ 상한 1.0만 적용. 착수 전(음수 진행율)은 하한 클램프하지 않는다 — 확정값 재현 조건
  ※ AK(진행률%) 컬럼 사용 금지 — FoEX(1:N)은 예상공수 0 고정으로 신뢰 불가
```

## 별도 3종 데이터 입력

작업지침 §2-2의 「별도 업로드 3종」(GCMS에 없는 데이터)을 화면에서 직접 입력합니다.

| 소스 | 갱신주기 | 산출 지표 | 검증 |
|---|---|---|---|
| **ONE AI 실적** | 월 | 총관리(이월+신규) · 완료 · 요금제별 · 월별 사용량 | 총관리 = 이월 + 신규 |
| **영업지원 실적** | 월 | 지원 · 계약 · 전환율 · 수주금액 4구분 | [G5] 전환율 = 계약÷지원 · 금액 4구분 합 · **1Q 합산 유지** |
| **FoEX 교육실적** | 주~월 | 1:N(정규+특별) · 단독 · 총교육 | [G6] 총교육 = 1:N + 단독 · **DX 별도 관리** |

### 입력 방법 2가지

```
① 엑셀에서 머리글 포함 영역 복사 → 붙여넣기 영역에 Ctrl+V → [붙여넣기 분석]
② [엑셀 파일 업로드] 에서 .xlsx / .csv 선택 → 자동 파싱
```

- **머리글 행 자동 탐지** — 제목·잡음 행이 위에 있어도 스키마 라벨과 가장 많이 일치하는 행을 찾습니다
- **컬럼 자동 매핑** — 실패 시 드롭다운으로 직접 지정
- **기준일 필수 입력** — §2-3 기준일 정렬 원칙에 따라 GCMS와 다르면 「별첨·정합성 검증」 화면에 병기·경고
- **브라우저 저장** — localStorage 보관. 차단 시 세션 메모리로 대체
- **양식 내려받기** — 스키마에 맞는 CSV 템플릿 제공

> `.xlsx` 파싱은 **외부 라이브러리 없이** ZIP 직접 파싱 + 브라우저 내장 `DecompressionStream('deflate-raw')`
> 으로 구현했습니다. standalone(`file://`)에서 인터넷 없이 동작합니다.
> `DecompressionStream` 미지원 브라우저에서는 붙여넣기를 사용하십시오.
