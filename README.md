# PKG 구축통합관리

더존비즈온 **PKG사업본부** A10(Amaranth10) 구축업무 통합 관리지표 플랫폼.

GCMS 구축진척 데이터를 원천으로 **KPI Definition Book(7 Pillar 30개 KPI)** 을 자동 산출하고,
NSM 화면정의서 기준의 PROJECT 등록 · 공수현황 화면을 함께 제공합니다.

## 실행 방법

### 방법 1 — 웹서버 없이 실행 (권장)

```
pkg-icm/index_standalone.html  →  더블클릭
```

데이터가 HTML에 내장된 단독 실행 파일입니다. 설치·인터넷 없이 동작합니다.

### 방법 2 — 웹서버로 실행 (개발용)

```bash
cd pkg-icm
python -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

### 데이터 갱신 후 재빌드

`pkg-icm/data/gcms_data.json` 을 교체한 뒤:

```bash
cd pkg-icm
python build_standalone.py
```

## KPI 산출 상태

각 KPI는 현재 원천 데이터로 산출 가능한 수준을 3단계로 표시합니다.

| 배지 | 의미 | 건수 |
|---|---|---|
| `자동산출` | GCMS 현행 데이터로 공식 그대로 산출 | 9개 |
| `대체산출` | 원천 필드 일부 부재. 가이드라인 명시 대체값으로 근사 산출 | 7개 |
| `연동 필요` | 원천 시스템 미연동. 로드맵 Phase에 따라 연동 후 산출 | 14개 |

> 대체산출 KPI는 카드 하단에 **어떤 필드가 없어 무엇으로 대체했는지**를 명시합니다.

### 현행 자동 산출 주요 지표

| KPI | 공식 | 현행값 | 목표 |
|---|---|---|---|
| 1.1 구축 완료율 | 완료(B)/접수(A)×100 | 39.9% | 70%+ |
| 1.6 반품률 | 반품(C)/접수(A)×100 | 0.4% | 0.5% 이내 |
| 3.1 FoEX 전환율(FAR) | FoEX방식건/전체건×100 | 49.4% | 50%+ |
| 6.3 RAG Red% | Red건/전체진행건×100 | 9.8% | 8% 이하 |
| 7.2 AI 기인 공수 절감률 | (표준−투입)/표준×100 | 19.6% | 15%+ |

## 프로젝트 구조

```
pkg-icm/
├── index.html               앱 셸 (탭 네비게이션)
├── index_standalone.html    ★ 단독 실행본 (빌드 산출물)
├── build_standalone.py      standalone 빌드 스크립트
├── css/app.css              디자인 토큰 + 컴포넌트
├── js/
│   ├── data.js              GCMS 데이터 정규화 (화면정의서 필드 매핑)
│   ├── kpi.js               ★ KPI 산출 엔진 (7 Pillar 30개)
│   ├── views.js             6개 화면 렌더러
│   └── app.js               라우터 / 부팅
└── data/gcms_data.json      원천 데이터 (1,375건)
```

### 공수 필드 매핑 (화면정의서 slide8·9 계산식)

```
계약공수      ← standard_hours
예상공수(유)  ← expected_hours
예상공수(무)  = 계약공수 − 예상공수(유)
투입공수(유)  ← invested_hours
잔여공수      = 예상공수(유) − 투입공수(유)
```
