📊 생산성 (Productivity)

생산성 = (표준공수 합계 / 투입공수 합계) × 100 (%)
완료 프로젝트 기준으로 표준공수(계약 기준 소요 공수) 대비 실제 투입공수의 효율을 측정합니다.
100% 초과 = 표준보다 적은 공수로 완료 (효율적), 100% 미만 = 초과 공수 투입.

✅ 완료율 (Completion Rate)

완료율 = (완료 건수 / 전체 건수) × 100 (%)
접수된 전체 프로젝트 중 상태가 '완료'인 건의 비율입니다. 진행 중인 프로젝트는 완료 예정일 기준으로 달성 가능성을 모니터링합니다.

⚠️ 지연율 (Delay Rate)

지연율 = (지연 건수 / 전체 건수) × 100 (%)
완료 예정일을 초과하여 진행 중인 프로젝트의 비율입니다. 지연율이 높을수록 구축자 CAPA 또는 고객 응대 이슈가 있음을 의미합니다.

⚙️ 공수효율 (Man-day Efficiency)

공수효율 = (표준공수 / 예상공수) × 100 (%)
PM이 산정한 예상공수 대비 표준공수 비율입니다. 1 미만 = 예상공수를 표준보다 크게 잡음(보수적 산정), 1 초과 = 표준보다 적게 잡음(공격적 산정).

📈 평균 진행률 (Avg. Progress)

평균 진행률 = Σ(각 프로젝트 진행률) / 전체 건수 (%)
현재 진행 중인 모든 프로젝트의 투입공수 기반 평균 진행률입니다. 단, 진행률=0인 미착수 건도 포함하여 평균을 산출합니다.

💹 구축자 1인당 평균 공수

1인당 공수 = 총 투입공수 / 구축 참여 인원 수 (MD)
전체 프로젝트에 구축자로 참여한 인원 수 기준으로 1인당 평균 투입공수를 산출합니다. CAPA 계획 수립 및 인력 배분 기준으로 활용합니다.
